# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in Casper Wallet, please report it privately through [GitHub private vulnerability reporting](https://github.com/make-software/casper-wallet/security/advisories/new). Attach proof-of-concept files there.

If you cannot use GitHub, email [security@make.software](mailto:security@make.software). Send text only: the mailing list drops attachments, so put PoC code inline or link to a private repository or gist.

Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

To help us triage and fix the issue quickly, please include as much of the following as you can:

- The type of issue and its potential impact
- Affected browser(s) and Casper Wallet version
- Step-by-step instructions to reproduce the issue (a proof of concept is very helpful)
- Any relevant configuration or environment details

We will acknowledge your report within 2 business days and keep you informed of the progress towards a fix. We kindly ask you to keep the details of your report confidential until a fix has been released.

## Supported Versions

Only the latest released version of Casper Wallet receives security updates.
